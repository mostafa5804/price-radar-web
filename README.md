# رادار قیمت — نسخه ۰.۰.۱

پیش‌نمونه‌ی واکنش‌گرای وب برای موبایل و دسکتاپ، آماده‌ی GitHub Pages.

## قابلیت‌های نسخه‌ی فعلی

- جست‌وجو و فیلتر روی فهرست آزمایشی کالاها
- مرتب‌سازی بر اساس قیمت
- افزودن و حذف کالا یا عبارت جست‌وجو از دیده‌بان
- ذخیره‌ی دیده‌بان‌ها در حافظه‌ی همان مرورگر
- فونت Vazirmatn تعبیه‌شده در صفحه

## محدودیت

قیمت‌ها نمونه هستند. دیده‌بان‌ها در مرورگر ذخیره می‌شوند، اما دریافت زنده‌ی قیمت، بررسی خودکار کاهش قیمت و ارسال اعلان هنوز پیاده‌سازی نشده‌اند و به بک‌اند نیاز دارند.

## فعال‌کردن GitHub Pages

در مخزن به **Settings → Pages** برو؛ در بخش **Build and deployment**، گزینه‌ی **Deploy from a branch** را انتخاب کن و شاخه‌ی **main** و پوشه‌ی **/(root)** را ثبت کن.

## مجوز فونت

فونت Vazirmatn تحت SIL Open Font License منتشر شده است. متن مجوز در فایل `OFL-Vazirmatn.txt` است.
