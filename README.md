# رادار قیمت — نسخه ۰.۰.۲

رابط وب فارسی برای جست‌وجوی زنده در دیوار و دیجی‌کالا. این نسخه از دادهٔ ساختگی استفاده نمی‌کند. سایت GitHub Pages فقط رابط را میزبانی می‌کند؛ برای کارکرد واقعی باید Worker و پایگاه‌دادهٔ Cloudflare هم مستقر شوند.

## آنچه این نسخه انجام می‌دهد

- جست‌وجوی زنده در دیوار و دیجی‌کالا با فیلتر شهر، دسته‌بندی، منبع و سقف قیمت
- ذخیرهٔ کالا یا عبارت جست‌وجو در Cloudflare D1
- بررسی زمان‌بندی‌شدهٔ دیده‌بان‌ها و ارسال پیام کاهش قیمت از راه ربات تلگرام
- ورود مدیر با رمز نگهداری‌شده به‌صورت Cloudflare Secret
- محدودیت تا ۸ دیده‌بان فعال برای کنترل تعداد درخواست به منابع قیمت

## وضعیت استقرار

تا وقتی بک‌اند Cloudflare راه‌اندازی و نشانی آن در `api-config.js` وارد نشده باشد، صفحه صریحاً می‌گوید به بک‌اند وصل نیست و نتیجه‌ای نمایش نمی‌دهد. رمز سایت، توکن تلگرام، شناسهٔ تلگرام و شناسهٔ پایگاه‌داده را هرگز در فایل‌های عمومی یا GitHub نگذار.

راهنمای ساخت D1، تنظیم Secretها، استقرار Worker، آزمایش دسترسی منابع و اتصال نشانی Worker به صفحه در [`backend/README.md`](backend/README.md) است.

## آزمایش محلی رابط

در ریشهٔ همین پوشه:

```bash
python -m http.server 8000
```

سپس `http://localhost:8000` را باز کن. برای دریافت نتیجهٔ واقعی، Worker باید مستقر و آدرس آن در `api-config.js` تنظیم شده باشد.
